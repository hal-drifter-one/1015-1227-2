# 1015-1227-2

## 概要

チャット、動画ストリーミング、ファイルアップロード機能を備えたWebアプリケーションです。
複数のユーザー間で動画再生を同期させることができます。

## 機能

- 💬 **チャット機能**: リアルタイムメッセージング、メッセージ削除、絵文字スタンプ、リアクション機能
- 🎬 **YouTube同期再生**: 複数ユーザー間で動画再生を同期
- 📁 **ファイルアップロード**: ファイルのアップロード・管理・ダウンロード（LocalStorage保管）
- 📱 **レスポンシブデザイン**: スマートフォンとPC両対応

## セットアップ

### 必要な環境

- Node.js (v14以上)
- npm

### インストール

```bash
# 依存パッケージをインストール
npm install
```

## 使用開始

### 1. サーバーを起動

```bash
npm start
```

**重要**: YouTubeの同期再生機能を使うには、サーバーが起動している必要があります。

**出力例:**
```
サーバーがポート 3000 で起動しました
http://localhost:3000 にアクセスしてください
```

### 2. ブラウザでアクセス

```
http://localhost:3000
```

### 3. 動画同期の確認

複数のタブ/ブラウザで同じURLを開いて、一つのタブで動画を再生/一時停止すると、他のすべてのタブで自動的に同期されます。

## 機能詳細

### チャット機能

#### メッセージ操作
- **メッセージをクリック** → 内容をコピー（スマートフォン対応）
- **🗑️ボタン** → 個別メッセージを削除
- **全削除ボタン** → 全メッセージを一括削除（確認ダイアログあり）

#### スタンプ機能
- **😊スタンプボタン** → スタンプメニューを表示
- 12種類の絵文字スタンプから選択可能

#### リアクション機能
- **👍 リアクションボタン** → メッセージにリアクション絵文字を追加
- 12種類のリアクション絵文字: 👍, ❤️, 😂, 😍, 🎉, 🔥, 👏, 🎯, 💯, 🚀, ⭐, 😢
- 同じリアクションをクリックすると数が増える
- すべてのデータはLocalStorageに保管され、ブラウザを閉じても保持

### 動画同期再生

- YouTubeの動画をリアルタイムで複数ユーザー間で同期
- 一人が再生/一時停止すると、他のユーザーの画面も自動更新
- 再生位置も同期

### ファイルアップロード

#### 保管場所
ファイルは**ブラウザのLocalStorage**に保管されます。
- データ量: ブラウザにより異なりますが、通常5-10MBまで
- 保持期間: ブラウザデータを削除するまで永続

#### 操作方法
1. サイドバーから「ファイルアップロード」セクションを使用
2. ファイルを選択して「アップロード」をクリック
3. ファイル情報が表示される（名前、サイズ、アップロード日時）
4. **DLボタン** → ファイルをダウンロード
5. **削除ボタン** → LocalStorageから削除

## トラブルシューティング

### YouTubeの動画が同期されない
- サーバーが起動しているか確認: `npm start`
- ブラウザコンソールでエラーを確認
- 複数のタブを開いて再度テスト

### ファイルがアップロードできない
- ブラウザのLocalStorageの容量確認
- 不要なファイルを削除してから再試行
- ブラウザのプライベートモードでは動作しない場合がある

### メッセージが消えてしまった
- ブラウザのキャッシュをクリアしていないか確認
- LocalStorage設定でアプリデータが削除されていないか確認
